Publishing workflow

  1. Save your edits.Save writes changes to the local SQLite database. It does not update the site files. Only records marked Published are written to the site.
  2. Sync data.Replaces only public-site/data with the manager's current Outpost, Character, Job, Archive, Gear, and Game data. Unmanaged files inside that folder are removed; site pages and assets stay unchanged.
  3. Export the full site.Builds a complete replacement folder at site-export/, including site pages, styles, scripts, assets, and current data. It leaves public-site/ untouched; copy the generated folder contents when you are ready to replace the site.
  4. Import site data.Replaces SQLite content with the current public-site/data. Unexported manager changes are discarded.
